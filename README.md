# SB24 Guide

Telegram bot for providing general account and service information.

## Profile

- **Name:** SB24 Guide
- **About:** សេវាបើកអាខោន និងព័ត៌មានណែនាំអំពីសេវាកម្ម
- **Description:** សេវាបើកអាខោន និងព័ត៌មានណែនាំអំពីសេវាកម្ម។ ព័ត៌មានលម្អិត និងការណែនាំអាចទទួលបាននៅក្នុង Bot។

## Commands

- /start
- /about
- /status

## Environment

Set `BOT_TOKEN` to the Telegram bot token.

## Deployment

The bot uses Telegram polling and can run as a long-running service on Render or another Python hosting platform.

This bot does not implement betting, wagering, odds, predictions, casino, lottery, or other gambling functionality.
